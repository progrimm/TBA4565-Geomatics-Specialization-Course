My GIS module

TBA4565 Specialization Subject: GI Science and Systems, NTNU, autumn 2026

Åmund Grimstad

This module builds practical GIS experience through small projects that are actually finished: tested, documented and running in the browser. Each one takes a single question from GI science, GI systems or 3D GIS and answers it with real data.

Projects

Project 1 GI Science

Projection Lab

How much does the Mercator projection inflate country areas, and how well does sec²φ predict it?

Here the map reads a static snapshot of its results. The full FastAPI and PostGIS stack runs with Docker Compose.

  • React
  • TypeScript
  • d3-geo
  • FastAPI
  • PostGIS
  • Docker
Open project: Projection Lab

Project 2 GI Systems

Trondheim 3D

Where is the nearest public shelter in Trondheim, and how far is the walk there?

A 3D city model with terrain, OSM buildings and DSB public shelters. Click the ground to route to the nearest shelter.

  • CesiumJS
  • React
  • OSM Buildings
  • DSB WFS
  • Vitest
Open project: Trondheim 3D

Project 3 3D GIS

3DGS Viewer

What can you learn from a 3D Gaussian splat file without uploading it anywhere?

Open your own PLY, SPZ, .splat, .ksplat or SOG file to see its facts, fix its up axis and measure distances. The file stays in your browser.

  • Spark
  • three.js
  • React
  • Vitest
Open project: 3DGS Viewer
