# Projection Lab Frontend

React and TypeScript render one interactive SVG map; D3 blends the raw Mercator and Eckert IV projections of 177 Natural Earth country geometries served from PostGIS through FastAPI. A checkbox toggles finite geographic circles approximating Tissot's indicatrix. Clicking or tapping a country selects it; Greenland is selected by default. The selection is highlighted, and the side panel compares its ellipsoidal, spherical and projected areas with the theoretical sec²(φ) at its centroid. Below the map, a **Distortion vs latitude** chart plots every country's Mercator area ratio against its centroid latitude.

The simplified Projection Lab interface uses a compact header, blend slider, circle checkbox, country panel and chart. Longer explanatory sections were replaced by a keyboard-accessible, collapsed Method disclosure. Since 2026-10-27 it explains, for non-experts, six points: Mercator is conformal; Eckert IV is equal-area; the red circles are Tissot's indicatrix; area grows by sec²φ (4× at 60°, about 33× at 80°) and why chart dots sit above the curve; the comparison uses a sphere rather than the WGS 84 ellipsoid (under 1% different for every country, measured from the CSV as −0.45% to +0.81%); and intermediate blends are not measured. The spherical denominator and distinction from screen area remain visible; intermediate blends remain explicitly unmeasured. Fetch/error handling is shared while country and statistics requests retain independent state.

The map requests `/api/countries`. The independent statistics request is `/api/countries/areas`, which returns all 177 precomputed records in one response; the panel and the chart both use it. The [Vite configuration](vite.config.ts) proxies `/api` to `http://127.0.0.1:8000` and removes the prefix. Start the [backend](../backend/README.md) and prepared [database](../database/README.md) before the frontend. A statistics failure does not prevent country loading, and neither request falls back to static data.

## Run Locally

Run these commands from this directory with a Node.js version supported by Vite (Node 24 was used for this project):

```powershell
npm ci
npm run dev
```

Open the Local URL printed by Vite. Use `npm run build` for TypeScript checking and production output, and `npm run lint` for ESLint. `npm run preview` serves a local build, not a deployable backend-routing solution; a production web server must route `/api/*` to the API with the prefix removed.

## Run the Full App in Docker

The Compose frontend uses a multi-stage Docker build: Node builds the Vite app, then Nginx serves the static output. Nginx proxies `/api/*` to the FastAPI service and removes the `/api` prefix, matching the Vite development proxy. No API or database URL is compiled into the frontend.

From the repository root, follow the [Compose setup](../README.md#run-the-map), then open <http://127.0.0.1:8080>. The database and API are also published locally at ports `5433` and `8000`, respectively, for development tools and direct checks. The frontend container waits for the API health check before starting.

The frontend Dockerfile uses the committed `package-lock.json` with `npm ci`. `.dockerignore` excludes local dependencies and generated build output.

## Source Layout

- [src/App.tsx](src/App.tsx): independent country and statistics loading, projections, per-country SVG paths with selection, and the country panel.
- [src/DistortionChart.tsx](src/DistortionChart.tsx): the latitude scatter, drawn with [`d3-scale`](https://d3js.org/d3-scale) (`scaleLinear` and [`scaleLog`](https://d3js.org/d3-scale/log)). Axes and the sec²φ curve are plain React SVG, and the chart width comes from a `ResizeObserver`.
- [src/countryAreas.ts](src/countryAreas.ts): response types, `fetchJson` and per-record validation (finite positive values).
- [src/App.css](src/App.css): map layout and geographic layer styling.
- [src/index.css](src/index.css): shared page styles and color variables.
- [src/d3-geo-projection.d.ts](src/d3-geo-projection.d.ts): local typings for the extension's `geoEckert4` and `geoEckert4Raw` functions; there is no published `@types/d3-geo-projection` package.
- [public/data/ne_110m_admin_0_countries.geojson](public/data/ne_110m_admin_0_countries.geojson): original versioned import source; still available as a static asset but not fetched by the map.
- [public/data/country_areas.json](public/data/country_areas.json): generated by `country_areas.py export`, in the same shape as `/api/countries/areas`. It is prepared for a later static GitHub Pages mode and **not fetched yet**.

The app currently assumes deployment at the site root. The map is fitted independently at each slider step; screen areas across blend values do not share a calibrated scale. The Mercator contribution clamps latitude to approximately +/-85.05 degrees; this introduces artificial polar behavior. Pure Eckert IV remains unmodified. Intermediate blends generally preserve neither angles nor area.

D3 calculates on a sphere; the database's geodesic areas use the WGS 84 ellipsoid. The API includes the USA/Sudan repairs while the static file remains unchanged. All 177 database geometries passed the clockwise-exterior/counterclockwise-hole check. The API preserves that D3-oriented winding, which differs from RFC 7946's recommendation.

## Selection and the Latitude Chart

- **Selecting a country.** Every country is its own SVG `<path>`, so clicking or tapping selects it. Hover darkens the land, and a highlight layer that ignores pointer events redraws the selected country. For keyboard and screen-reader users the panel also has a native country `<select>`, because the map SVG is a single `role="img"` element.
- **The panel.**
  - Antarctica shows a note that it was clipped at ±85.05°, with the fraction of its area kept.
  - A country whose status is not `ok` (only Sudan) shows its check flag.
  - The table adds a sec²(φ) row at the centroid latitude.
  - A final note gives the Mercator ratio divided by that prediction.
- **The chart.**
  - x is the area-weighted centroid latitude on a linear scale. y is the Mercator area ratio on a log scale, because the ratios range from about 1 to 25.
  - The red curve is sec²φ, the area scale of a point at that latitude.
  - Points are hollow when the country was clipped (Antarctica) and have a red outline when they carry a check flag.
  - Hovering shows a tooltip; clicking or tapping a point selects that country on the map. The selected point is gold and keeps its tooltip, which also covers touch screens without hover.
  - No chart library was added. `d3-scale` is one of the d3 modules, and it and its types were installed with npm.
- **Reading the chart.** Small countries sit on the curve. Countries spanning many degrees of latitude sit above it, because the ratio is the area-weighted mean of sec²φ, and sec²φ is convex. See [results/summary.md](../results/summary.md).

## Accessibility

- **Keyboard path.** Tab order: blend slider → Circles checkbox → Country `<select>` → chart → Method → Natural Earth link. Each stop shows a 2 px ink outline (`:focus-visible`).
  - The `<select>` selects any country. Map paths are mouse/touch targets only, because the map SVG is a single `role="img"`.
  - The focused chart (`role="group"`) takes ArrowRight/ArrowUp to the next country north by centroid latitude, ArrowLeft/ArrowDown to the next south, and Home/End to the southernmost (Antarctica) and northernmost (Greenland). The keys don't scroll the page.
  - A visually hidden `aria-live` line announces the selected country's latitude, Mercator ratio and sec² prediction. The hover tooltip itself is `aria-hidden`.
- **Contrast.**
  - Text: the 19 checked text styles measured from computed colours at runtime have a minimum of 5.30:1 (muted grey on the page background), above the WCAG AA 4.5:1.
  - Non-text: chart points use an 80% fill (3.79:1 against the background) with a full-opacity outline (5.72:1). The sec²φ curve is 5.76:1. The selected map country has a 2 px dark border, 4.51:1 against the land fill; the gold fill alone is only 1.49:1.
- **Narrow screens.** At 320 px there is no horizontal overflow. Below 600 px the chart uses five latitude ticks (60°S–60°N) so the labels don't collide.
- **Network errors.** If a request cannot reach the server, the alert now reads "… the server could not be reached" instead of the browser's "Failed to fetch".

## Country Results During Morphing

Both endpoint results stay visible. At 0% Mercator is marked current; at 100% Eckert IV is marked current. At intermediate positions neither row is current and the panel explicitly says the blend area is not calculated. Ratios are never interpolated or inferred from screen size. Area values are displayed in square kilometers and rounded for readability; API values retain square-meter precision.

The spherical area is the denominator for both ratios. The WGS 84 ellipsoidal area is a separate reference, not the denominator. See the [backend method](../backend/README.md#country-method) for the radius, numerical convergence, and limitations. A rounded Eckert IV ratio of 1 is consistent with a small nonzero numerical approximation error.
