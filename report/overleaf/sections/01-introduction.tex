\paragraph{How I worked.} I used the AI coding assistant Claude Code \citep{claudecode} throughout, in two different roles. In the first part of Projection Lab, it acted as a tutor: I wrote and ran the code myself, and it explained concepts and pointed me to the official documentation. In Trondheim 3D, the 3DGS Viewer and the final sprint (27--30 October), it wrote the code while I set the goals, chose between alternatives, reviewed the changes and checked the result in the browser. Two habits held throughout: a change only counted as done when it had been checked with something runnable (tests, a build, or a screenshot at desktop and phone width), and every project README records what was verified and what was not. I reflect on this way of working in \cref{sec:reflection}.

The rest of the report has one section per project (\cref{sec:p1,sec:p2,sec:p3}), each covering the purpose, what I built, the technologies and what I learned. \Cref{sec:website} describes the shared website, and \cref{sec:reflection} sums up what I gained.
